# Security reporting

Do not open a public issue for a suspected malicious or tampered FlowCense release, exposed credential, or signing-key incident.

Use GitHub's private vulnerability reporting for this repository when it is enabled. If that option is unavailable, contact the FlowCense repository owner privately through the verified support channel already provided to your organization. Do not attach secrets, private keys, device credentials, customer data, or full diagnostic archives to an unencrypted message.

The release manifest's detached signature is the authorization boundary. SHA-256 values in the same public repository detect corruption but do not independently protect against repository compromise.
